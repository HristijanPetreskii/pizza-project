
# 🍕 Forno – Artisan Pizza Website

A modern, responsive website for an artisan pizza restaurant, built using HTML5 and CSS3.

## 📌 About the Project

Forno is a restaurant website concept designed to showcase a clean, modern, and user-friendly interface for an artisan pizza business.

The website includes a navigation bar, hero section, restaurant introduction, pizza menu, special offers, contact information, and footer.

## ✨ Features

- Responsive layout for desktop, tablet, and mobile devices
- Semantic HTML5 structure
- Modern and clean user interface
- Navigation menu with section links
- Pizza menu cards
- Restaurant information and special offers
- Contact section
- CSS hover effects and transitions
- Organized layout using Flexbox and CSS Grid

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Variables

## 📱 Responsive Design

The website is designed to adapt to different screen sizes, providing a consistent browsing experience across desktop, tablet, and mobile devices.

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/forno-pizza-website.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
